# ml-practice

Welcome to my Machine Learning practice repository! This repo tracks my learning journey, code experiments, and mathematical notes as I study foundational ML algorithms from scratch and using **Scikit-Learn**.

---

## 📌 Topics Covered

- **Linear Regression**: Understanding matrix notation, vector derivatives, and the Sum of Squared Errors (SSE).
- **Gradient Descent**: Optimizing weights, handling cost surfaces, local vs. global minima, and learning rates.
- **Model Evaluation ($E_{rms}$)**: Calculating Root Mean Squared Error to judge model performance.
- **Polynomial Regression & Overfitting**: Balancing model complexity, train/test splits, and understanding bias-variance tradeoffs.

---

## 🛠️ Tech Stack & Tools

- **Language:** Python 3.x
- **Libraries:** NumPy, Pandas, Scikit-Learn, Matplotlib, Seaborn
- **Environment:** Visual Studio Code
